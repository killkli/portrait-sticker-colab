# 聊天表情動作庫與常用標語 (Chat Expressions & Slogans)

本文件提供高頻聊天貼圖的動作表情庫、視覺符號與中英文標語對照表。

---

## 經典 9 宮格表情庫 (預設 3x3 Grid)

| 編號 | 情境主題 | 動作與視覺描繪 | 繁中標語 | 英文標語 |
|:---:|:---|:---|:---:|:---:|
| 1 | **打招呼 / 哈囉** | 燦爛微笑、熱情揮手、頭頂跳出小音符 | 嗨！ / 哈囉 | HELLO! / HI! |
| 2 | **讚 / OK / 收到** | 單手或雙手比大拇指、自信眨眼、閃閃發光 | OK啦！ / 讚！ | OK! / THUMBS UP |
| 3 | **謝謝 / 感恩** | 雙手合十微鞠躬、水汪汪星星眼、小花圍繞 | 謝謝泥 / 感恩 | THANKS! / THANK YOU |
| 4 | **哈哈 / 狂笑** | 捧腹大笑、笑到流眼淚、張嘴爆笑 | 哈哈哈 / 笑死 | LOL! / HAHAHA |
| 5 | **哭哭 / 崩潰** | 瀑布狀眼淚噴發、咬手帕、跪地崩潰 | 嗚嗚嗚 / 崩潰 | NOOO! / CRYING |
| 6 | **生氣 / 爆炸** | 額頭冒青筋、雙頰漲紅、雙耳噴蒸氣或頭頂著火 | 氣炸！ / 怒！ | ANGRY! / RAGE |
| 7 | **愛心 / 撒嬌** | 雙手比手指愛心、抱著大紅心、臉頰泛紅飛吻 | 愛你唷 / 啾咪 | LOVE YOU / XOXO |
| 8 | **晚安 / 累癱** | 裹在軟綿綿被子裡打瞌睡、嘴邊掛口水泡、浮現 Zzz | 晚安安 / 累癱 | GOODNIGHT / ZZZ |
| 9 | **疑惑 / 思考** | 歪著頭抓抓頭髮、頭頂浮現大大的立體「???」 | 蛤？？ / 思考中 | WHAT?! / HUH? |
